# MWICombatSimulator

### How to run locally for development purposes

Install dependencies: 

```bash
npm install
```

Build webpack bundle:

```bash
npm run build
```

Run locally:

```bash
npm start
```

### Simulation result archives

Saving a result compresses the current group and map settings into browser local storage. Use **Load** on an archive entry to restore them. Older entries can only load the configuration they saved.
